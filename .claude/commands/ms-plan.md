description: 마일스톤 정책을 근거로 AI 개발용 plan.md · tasks.md를 쓴다
argument-hint: <slug>
---

요청: $ARGUMENTS

1. `milestones/<slug>/`의 `milestone.md`, `specs/*.md`, (있으면) `devspec.md`, 관련 `api/` · `data/` 문서를 읽는다.
2. `plan.md`를 채운다: 대상 정책 표(코드 · 한 줄 요약), 영향 범위(API · 데이터 문서 링크), 설계 결정, 단계, 정책 코드별 테스트 방법, 위험 · 미결 사항.
3. `tasks.md`를 채운다: 반나절 안에 끝나는 크기로 나누고, 작업마다 근거 정책 코드와 완료 기준을 쓴다. 의존 순서대로 놓는다.
4. 정책에 없는 구현 세부는 만들지 않고 `[확인 필요]`로 남긴다. 정책 자체가 모호하면 해당 코드를 미결 사항에 적는다.
5. API · 데이터 변경이 필요하면 `api/` · `data/`에 초안을 쓰고 `x-policy` · 근거 정책 칸으로 정책 코드를 잇는다.
6. 이 파일들은 PRDstar로 올리지 않는다. 바뀐 파일과 `[확인 필요]` 목록을 보고한다.
